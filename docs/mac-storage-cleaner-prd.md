# Mac 存储清理应用需求文档（PRD）

## 1. 文档信息
- 产品名称：CleanMacApp（暂定）
- 平台：macOS（优先支持 macOS 13+）
- 文档版本：v1.0
- 日期：2026-02-26
- 状态：草案（待评审）

## 2. 背景与问题定义
Mac 用户长期使用后，会出现磁盘空间不足、系统变慢、下载目录和缓存文件堆积等问题。现有方案要么过于复杂（手动在 Finder 里逐个清理），要么不透明（“一键清理”但不展示细节、风险不可控）。

本产品目标是提供一个“安全、可解释、可回滚”的存储清理工具，帮助用户快速释放空间，同时避免误删重要文件。

## 3. 产品目标
## 3.1 核心目标
1. 在 3 分钟内帮助用户定位主要空间占用来源。
2. 在 1 次清理流程中可稳定释放可观空间（例如 >3GB，视用户设备情况而定）。
3. 保证清理过程可追溯、可撤销（至少支持“移到回收站”模式）。

## 3.2 非目标（v1 不做）
1. 不做杀毒/安全防护。
2. 不做内存加速、CPU 优化等与存储无关能力。
3. 不接入云盘文件搬迁（如 iCloud/Dropbox 智能迁移）作为首版必备能力。

## 4. 目标用户
1. 普通办公用户：磁盘常年不足，不清楚该删什么。
2. 内容创作者：视频、图片、工程文件占用高，需快速识别大文件与重复文件。
3. 开发者：构建缓存、日志、依赖缓存多，需安全清理技术目录（如 Xcode DerivedData、Homebrew 缓存）。

## 5. 用户痛点
1. 不知道空间到底被什么占用。
2. 手工排查成本高，且容易误删。
3. 系统“存储管理”不够细，缺少批量处理和规则建议。
4. 对自动清理不信任，希望先预览再执行。

## 6. 使用场景
1. 收到“启动磁盘空间不足”提醒后，想 10 分钟内释放至少 10GB。
2. 安装大型软件/系统更新前，需要快速腾挪空间。
3. 周期性维护，希望按建议清理浏览器缓存、下载目录、旧安装包、重复文件。

## 7. 功能范围
## 7.1 MVP（首版必须）
1. 磁盘扫描总览
   - 展示总容量、已用、可用。
   - 按类别展示占用：应用、文稿、下载、图片、视频、音频、缓存、系统/其他。
   - 支持按文件夹/类型 Top N 占用列表。
2. 大文件发现
   - 可配置阈值（默认 >500MB）。
   - 列表展示文件名、路径、大小、最近访问时间。
   - 支持排序、筛选、批量勾选。
3. 重复文件检测
   - 基于文件哈希（如 SHA-256）+ 大小做重复识别。
   - 分组展示重复项，默认保留“最近修改版本”，其余建议清理。
   - 支持用户手动改选保留项。
4. 常见垃圾清理
   - 用户缓存目录（如 `~/Library/Caches`）可视化清理。
   - 下载目录旧文件建议（如 30/60/90 天未访问）。
   - 安装包与压缩包（`.dmg`, `.pkg`, `.zip`）聚合展示。
5. 安全清理流程
   - 清理前二次确认（显示预计释放空间与影响范围）。
   - 默认“移到回收站”而非永久删除。
   - 支持查看清理历史（时间、条目数、释放空间）。
6. 基础设置
   - 扫描范围配置（全盘/指定目录）。
   - 清理默认规则配置（大文件阈值、旧文件天数）。

## 7.2 v1.1+（增强）
1. 应用残留文件识别（卸载后残留配置/缓存）。
2. 开发者清理模板（Xcode、npm/yarn/pnpm、Docker、Homebrew）。
3. 智能建议卡片（“预计可释放 xx GB，风险低”）。
4. 定期扫描提醒（本地通知）。

## 8. 关键流程（用户旅程）
1. 首次打开
   - 说明权限用途（仅用于扫描和清理用户选定文件）。
   - 引导选择扫描范围（建议“快速扫描”）。
2. 扫描中
   - 显示进度、当前扫描目录、预计剩余时间。
3. 扫描结果页
   - 先看“可释放空间总计”。
   - 下钻到“大文件/重复文件/缓存”等模块。
4. 执行清理
   - 用户勾选条目 -> 二次确认 -> 执行。
5. 清理完成
   - 展示本次释放空间、清理项、后续建议。

## 9. 功能细化需求
## 9.1 扫描引擎
1. 支持增量扫描（保存上次索引，减少重复耗时）。
2. 扫描过程低优先级运行，避免明显卡顿。
3. 对系统受保护目录异常要可恢复（跳过并记录）。

## 9.2 文件操作
1. 批量移动到回收站。
2. 失败重试与失败项报告（权限不足、文件占用）。
3. 同名冲突处理（按系统回收站行为）。

## 9.3 数据与日志
1. 本地存储扫描索引、历史记录与用户设置。
2. 默认离线工作，不上传文件名/路径内容到云端。
3. 若后续有遥测，仅收集匿名产品事件且默认可关闭。

## 10. 非功能需求
1. 性能
   - 1TB SSD，普通用户目录首次全量扫描目标 <10 分钟（硬件差异允许波动）。
   - 快速扫描（桌面/下载/文稿/缓存）目标 <2 分钟。
2. 稳定性
   - 清理流程异常中断不应导致数据损坏。
   - 关键流程崩溃率目标 <0.5%。
3. 易用性
   - 新用户首次完成清理流程成功率 >85%。
4. 可维护性
   - 模块化设计：扫描、分析、清理、UI 分离。

## 11. 权限与安全
1. 系统权限
   - 文件与文件夹访问权限（按 macOS 权限模型申请）。
   - 仅在用户触达相关功能时按需申请权限。
2. 安全策略
   - 不默认扫描敏感系统目录。
   - 清理前显示完整路径与影响说明。
   - 默认不提供“不可恢复删除”快捷入口（降低误删风险）。

## 12. 信息架构与页面
1. 首页（概览）
   - 存储环图、可释放空间、推荐清理卡片。
2. 扫描结果页
   - Tab：大文件 / 重复文件 / 缓存 / 下载旧文件 / 安装包。
3. 清理确认弹窗
   - 清理项统计、预计释放空间、风险提示。
4. 历史记录页
   - 每次清理记录、详情、失败项查看。
5. 设置页
   - 扫描范围、规则阈值、通知、隐私选项。

## 13. 验收标准（MVP）
1. 能完成一次从扫描到清理的闭环流程，且默认走回收站。
2. 能识别并展示大文件、重复文件、缓存文件三类可清理项。
3. 每次清理后可查看历史记录和释放空间。
4. 在常见错误（权限不足、文件占用）下有明确提示，不崩溃。
5. 用户可在设置中调整扫描范围和清理规则。

## 14. 指标设计（上线后观察）
1. 激活指标：安装后 24 小时内完成首次扫描率。
2. 核心价值指标：人均单次释放空间（GB）。
3. 体验指标：扫描完成率、清理完成率、误删投诉率。
4. 留存指标：7 天内二次使用率。

## 15. 里程碑建议
1. 里程碑 A（1-2 周）：原型与技术验证
   - 完成扫描引擎 POC、文件分类策略、性能基线测试。
2. 里程碑 B（2-4 周）：MVP 开发
   - 实现概览、大文件、重复文件、缓存清理、回收站清理链路。
3. 里程碑 C（1-2 周）：稳定性与发布准备
   - 权限与异常处理、回归测试、安装包与版本发布。

## 16. 风险与应对
1. 风险：误删关键文件
   - 应对：默认回收站、二次确认、关键目录黑名单。
2. 风险：扫描过慢导致流失
   - 应对：快速扫描模式、增量扫描、进度可视化。
3. 风险：权限受限导致功能不可用
   - 应对：清晰授权引导、失败原因提示、替代路径建议。

## 17. 开发建议（技术方向）
1. 客户端技术栈（建议）
   - UI：SwiftUI（macOS 原生体验）
   - 核心逻辑：Swift + FileManager + 安全沙箱适配
   - 数据存储：SQLite/CoreData（用于索引和历史）
2. 架构建议
   - `Scanner`（扫描）/ `Analyzer`（分析）/ `Cleaner`（清理）/ `AuditLog`（日志）四模块分层。
3. 测试建议
   - 单元测试：文件分类、重复检测、规则过滤。
   - 集成测试：扫描到清理闭环。
   - 稳定性测试：大目录、权限异常、清理中断恢复。

## 18. 待确认问题
1. 产品是否需要 App Store 上架（影响沙箱策略与权限模型）。
2. 是否需要“永久删除”高级选项（默认关闭）。
3. 是否加入开发者清理模板作为首版特性。
4. 是否做免费版/付费版功能边界（例如高级扫描规则）。
