# CleanMacApp 执行路线图（自主推进版）

> 状态更新时间：2026-03-22（与 `main` 分支同步）

## 1. 目标
在不依赖分发流程的前提下，连续完成可用 MVP：
1. 可视化扫描与结果展示。
2. 候选生成（大文件/缓存/重复文件）。
3. 清理执行（回收站）与作业审计。
4. 稳定性与性能优化。

## 2. 已完成基线
1. Core 扫描索引闭环（SQLite）。
2. 候选生成（大文件、缓存、重复文件）。
3. 清理执行与作业结果持久化。
4. CLI 端到端可运行。
5. SwiftUI 桌面端可独立完成扫描 -> 推荐 -> 清理 -> 历史闭环。
6. 全盘扫描内存峰值治理（扫描背压、轻量聚合、维护回收）。
7. 清理后索引同步修复（避免已删除文件被再次推荐）。
8. 全盘权限引导 UI（状态显示 + 打开设置 + 重新检查）。
9. 桌面应用品牌统一（`CleanMacApp` 名称与自定义图标）。

## 3. 当前执行阶段
## 阶段 A：桌面壳层（已完成）
交付内容：
1. SwiftUI 桌面应用入口。
2. 扫描控制区（快速扫描/自定义路径）。
3. 实时进度区（文件数、体积、当前路径）。
4. 候选汇总与列表（large/cache/duplicate）。
5. 按类型一键清理（move to trash）。

验收标准：
1. 不依赖 CLI 即可完成一次扫描到清理。
2. 清理后候选可刷新并反映最新状态。

## 阶段 B：历史与可恢复（已完成）
交付内容：
1. 清理作业历史列表。
2. 失败项详情与重试按钮。

验收标准：
1. 可看到 job 维度成功/失败/释放空间。
2. 失败项可单独重试并更新结果。

## 阶段 C：性能与增量（已完成首轮）
交付内容：
1. 增量扫描策略（基于 mtime/size/inode）。
2. 推荐构建过程并发限流。
3. 大目录性能基准脚本。

验收标准：
1. 快速扫描耗时明显下降。
2. 重复检测不会长期阻塞 UI 线程。

## 4. 当前重点（下一阶段）
1. 统一安装与启动入口（固定 `/Applications/CleanMacApp.app`），减少多实例/多权限主体混淆。
2. 历史页增强：补充成功清理项明细视图（当前偏失败项追踪）。
3. 补齐自动化测试（当前以手工验证和脚本基准为主）。
4. 持续优化全盘扫描取消响应与权限异常提示细节。

## 5. 不确定项处理机制
1. 不影响主链路的问题：先按默认策略落地，并在 `README` 标注。
2. 影响数据安全或行为语义的问题：暂停并请求你确认。
3. 影响删除行为的问题：默认保守（不做永久删除）。

## 6. 默认决策（除非你明确改）
1. 大文件阈值：500MB。
2. 快速扫描目录：Desktop/Documents/Downloads/Library/Caches。
3. 清理动作：仅回收站。
4. 重复文件保留策略：保留最近修改文件。
