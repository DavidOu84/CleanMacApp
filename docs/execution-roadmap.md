# CleanMacApp 执行路线图（自主推进版）

## 1. 目标
在不依赖分发流程的前提下，连续完成可用 MVP：
1. 可视化扫描与结果展示。
2. 候选生成（大文件/缓存/重复文件）。
3. 清理执行（回收站）与作业审计。
4. 稳定性与性能优化。

## 2. 已完成基线
1. Core 扫描索引闭环（SQLite）。
2. 候选生成（大文件、缓存、重复文件）。
3. 清理执行与作业结果持久化。
4. CLI 端到端可运行。

## 3. 当前执行阶段
## 阶段 A：桌面壳层（进行中）
交付内容：
1. SwiftUI 桌面应用入口。
2. 扫描控制区（快速扫描/自定义路径）。
3. 实时进度区（文件数、体积、当前路径）。
4. 候选汇总与列表（large/cache/duplicate）。
5. 按类型一键清理（move to trash）。

验收标准：
1. 不依赖 CLI 即可完成一次扫描到清理。
2. 清理后候选可刷新并反映最新状态。

## 阶段 B：历史与可恢复
交付内容：
1. 清理作业历史列表。
2. 失败项详情与重试按钮。

验收标准：
1. 可看到 job 维度成功/失败/释放空间。
2. 失败项可单独重试并更新结果。

## 阶段 C：性能与增量
交付内容：
1. 增量扫描策略（基于 mtime/size/inode）。
2. 推荐构建过程并发限流。
3. 大目录性能基准脚本。

验收标准：
1. 快速扫描耗时明显下降。
2. 重复检测不会长期阻塞 UI 线程。

## 4. 不确定项处理机制
1. 不影响主链路的问题：先按默认策略落地，并在 `README` 标注。
2. 影响数据安全或行为语义的问题：暂停并请求你确认。
3. 影响删除行为的问题：默认保守（不做永久删除）。

## 5. 默认决策（除非你明确改）
1. 大文件阈值：500MB。
2. 快速扫描目录：Desktop/Documents/Downloads/Library/Caches。
3. 清理动作：仅回收站。
4. 重复文件保留策略：保留最近修改文件。
